# Cultivar

Cultivar is an AI-assisted agriculture decision platform that combines:

- Sustainability scoring from farm conditions
- Market price prediction from economic and seasonal indicators
- Actionable advisory text generated by Gemini for farmer-friendly decision support

The project includes a FastAPI backend and a redesigned Vite + React frontend.

## What Is Improved

- Removed hardcoded secret usage from tracked config and switched to placeholder-based env setup.
- Hardened backend request handling with cleaner Pydantic v2 usage.
- Rebuilt the frontend UX with a modern responsive interface and better form handling.
- Added robust API error display and typed numeric payload normalization.
- Consolidated project docs and startup flow in this README.

## Backend Setup

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Update [.env](.env):

```env
GOOGLE_API_KEY=YOUR_GOOGLE_API_KEY
TF_ENABLE_ONEDNN_OPTS=0
```

4. Run backend:

```bash
uvicorn app:app --reload
```

Backend URL: http://localhost:8000

## Frontend Setup

From [frontend/cmd](frontend/cmd):

```bash
npm install
npm run dev
```

Frontend URL: http://localhost:5173

Optional API override:

- Set Vite env var `VITE_API_BASE_URL` if backend runs on a different host.

## API Endpoints

- `POST /predict/sustainability`
- `POST /predict/market`
- `GET /health`

Interactive docs:

- http://localhost:8000/docs
